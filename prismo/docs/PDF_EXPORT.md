# Exportación de reportes

Los botones **Vista previa** y **Descargar PDF** usan pdfmake en el navegador. La vista previa abre el mismo PDF en un diálogo antes de guardarlo. Convierte el JSON de Tiptap y las instantáneas guardadas en títulos, párrafos, listas, tablas, gráficos vectoriales sencillos y referencias enlazadas. Incluye el logo de Prismo, pie con número de página y márgenes A4. El borrador y el token de INEGI no salen del navegador durante la exportación.

El 13/11/2026 se comprobó una descarga E2E que contiene dos dashboards, valores, fuente, enlaces y un texto largo. El PDF generado tuvo nueve páginas; una lectura del archivo confirmó su cabecera PDF, las nueve imágenes del sello, los valores y los enlaces. La salida del texto conserva caracteres acentuados en la codificación del PDF, aunque el extractor pypdf usado en esta comprobación los muestra como caracteres de reemplazo; conviene validar también copia de texto en lectores PDF antes del despliegue.

El editor muestra hojas A4 y desplaza bloques completos a la siguiente hoja cuando caben. Para un párrafo más alto que una hoja inserta separadores visuales entre líneas. Una prueba de navegador comprueba que el texto de un párrafo largo no cae en la franja entre hojas; aún debe revisarse visualmente con combinaciones de fuentes, tamaños, listas y dashboards antes del despliegue. El PDF pagina el texto automáticamente. Arial y Verdana se aproximan con Helvetica en el PDF; Times New Roman y Georgia se aproximan con Times, mientras el editor usa las fuentes del sistema. Esta correspondencia se debe revisar antes de prometer fidelidad tipográfica exacta.
